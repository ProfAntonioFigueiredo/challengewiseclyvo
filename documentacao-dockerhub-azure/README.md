# Documentacao FIAP DevOps - Cenarios Java MySQL e Java Oracle

Esta pasta contem a documentacao tecnica em HTML para apoiar a aula de DevOps Tools & Cloud Computing e a correcao do Challenge 2026.

O material principal contem dois cenarios no mesmo arquivo:

- arquitetura de referencia desenhada no proprio HTML;
- Cenario 1 - Aula pratica em 8 passos: aplicacao Java com Spring Boot e MySQL em containers Docker;
- Cenario 2 - Challenge/correcao em 8 passos: aplicacao Java com Spring Boot e Oracle em container Docker usando `gvenzl/oracle-xe:21-slim`;
- publicacao da imagem da aplicacao no Docker Hub;
- execucao de App e Banco em uma VM Linux na Azure;
- criacao da infraestrutura com Azure CLI;
- evidencias e criterios de avaliacao conforme o material do Challenge.
